# PRXcalorie

🚀 An AI-powered web application for tracking calories and nutrition.

## ✨ Features

- 🍎 Food calorie estimation
- 📊 Daily calorie tracking
- 🤖 AI-powered analysis
- 📱 Responsive design
- 📈 Progress dashboard

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- Supabase
